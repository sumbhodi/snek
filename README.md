# Snek

A classic snake game implementation.

## About

This repository contains a snake game with HTML/web interface and Android APK distribution.

## Files

- **HTML Game** - Web-based version of the game
- **Background Assets** - PNG graphics for the game
- **APK** - Android application package for mobile devices

## Getting Started

### Web Version

Open the HTML file in your web browser to play the web version.

### Android Version

Install the APK file on your Android device to play the mobile version.
